Design Notes

Tranche section (Screen A): Exact same TrancheSection component reused from BandsClient. No duplication — extract to a shared component file.


Financials at bottom (Screen A): Collapsed view by default (show values). Tap "Edit" to expand inline inputs. "Save" re-runs band calculation with new inputs and updates DB without AI call.


TMCV / no-data case (Screen B): When bands are missing or last generation failed due to missing data, show the financials card prominently with the errored field highlighted red. "AI Fill" button triggers the existing bands generate route. Manual save bypasses AI entirely.


Anchor field visibility: Show only the fields relevant to the category — PE stocks show EPS only (not EBITDA/shares), EV/EBITDA shows OpProfit/Debt/Cash/Shares, Banks show BVPS, Insurance shows EV + Shares.
