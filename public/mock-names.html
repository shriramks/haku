Key principle: symbol stays primary (bold, large). Name is purely for recognition — not actionable.

Implementation Approach

A single file lib/stock-names.ts exports a lookup dictionary:

BELNHIEXLTITC…

A helper getStockName(symbol) returns the name or undefined. When undefined, show nothing (don't show a blank line). When defined, show below the symbol in Caption (11-12px) muted color.

No DB changes needed — names are purely presentational and live in the codebase.
