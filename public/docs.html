Folio

Personal stock portfolio tracker · Indian markets

📋 What is Folio?

Folio helps you manage a systematic buy plan for Indian equities. You set an annual budget, allocate it across stocks, generate AI-powered buy bands, and track purchases through tranches. Everything is private — your data is only visible to you.

🗺️ The Four Screens

Allocation

Your portfolio at a glance — how much is allocated to each stock as a % of annual budget, how much you've spent, and what remains. The bar chart shows your current allocation split.

Buy Bands

The core screen. Each stock shows a price band with four zones:

DEEP Exceptional value — buy aggressively
BUY Within target range — buy normally
MID / HOLD Fairly valued — hold, don't add
TRIM Overvalued — consider trimming

The black pin on the bar shows where the current market price (CMP) sits.

Transactions

Log every buy and sell. Tap + in the bottom bar to add a trade — enter the stock symbol, quantity, price, and date. The app computes the amount automatically.

Plan

Set your FY budget and allocate percentages to each stock. You can create a new plan each financial year, carrying over unspent amounts automatically.

⚡ Getting Started

1
Create a Plan
Go to Plan → tap "New Plan", set your FY budget (e.g. ₹24L), add stocks with allocation %.
2
Add a Gemini API key
Tap the profile icon → AI Settings → paste your free Gemini API key. This powers band generation.
3
Generate Buy Bands
Go to Buy Bands → tap ⚡ Bands on any stock. The AI fetches financials and computes price zones based on the stock's category and valuation model.
4
Review Tranches
After generating bands, tranches (suggested buy orders) are created automatically. Each tranche is a quantity × price within the buy zone. Mark them done as you execute.
5
Log Transactions
After buying, tap + and log the trade. The remaining budget updates instantly.

🐻 Bear / Normal / Bull

On each stock in Buy Bands, you can set the market outlook:

  • Bear — two weak quarters recently. Tightens all band prices by 10% (more conservative).
  • Normal — baseline valuation.
  • Bull — two strong quarters. Applies premium multiples for eligible categories.

This affects both band prices and generated tranches.

🤖 How Band Generation Works

Each stock is assigned a category (Defence, FMCG, Pharma, etc.). The AI fetches EPS, operating profit, debt, and shares from Screener.in, then applies category-specific valuation multiples (PE, EV/EBITDA, or P/BV) to compute four price zones.

Regenerate bands whenever you want fresher data — each run creates a new versioned record.
